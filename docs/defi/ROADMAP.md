# 🗺️ Roadmap

> Current focus, priorities, and future plans for PARALLAX Exchange — including the path to SNS governance.

---

## Philosophy

> **SNS will be a meaningful option later if the community and usage keep growing. At this stage, we are focusing on making the product actually useful first: better trading UX, LP incentives, real volume, and Agent Kit integrations.**

We believe governance should follow utility, not precede it. A DAO governing a product nobody uses is just bureaucracy. Our priority order:

1. **Make it work** — reliable, fast, correct
2. **Make it useful** — real traders, real volume, real value
3. **Make it governed** — decentralize control when there's something worth governing

## Long-Term: Path to SNS

### What Is SNS?

The **Service Nervous System (SNS)** is ICP's framework for decentralizing canister control:
- Token-based governance (1 token = 1 vote, with neuron staking)
- Community-controlled canister upgrades
- Treasury management by token holders
- Proposal-based decision making

### When Will PARALLAX Launch SNS?

**Prerequisites** (all must be met):

| Prerequisite | Why | Status |
|--------------|-----|--------|
| Consistent daily volume | Proves product-market fit | ⏳ Building |
| Active LP community | Shows sustainable liquidity | ⏳ Building |
| Agent Kit adoption | Developer ecosystem exists | ⏳ Building |
| Security audit | Trust in canister code | 📋 Planned |
| Token economics finalized | Fair, sustainable tokenomics | 📋 Planned |
| Community size > 1000 | Meaningful governance participation | ⏳ Growing |

### SNS Launch Plan (When Ready)

1. **Token design** — utility, governance, and fee-sharing mechanics
2. **Initial distribution** — fair launch via SNS swap (NNS-governed)
3. **Neuron setup** — founding team neurons with dissolve delays
4. **Control transfer** — canister controllers → SNS DAO
5. **Proposal system** — community votes on upgrades, parameters, treasury

### What Changes With SNS

| Aspect | Pre-SNS (Now) | Post-SNS |
|--------|---------------|----------|
| Canister upgrades | Team-controlled | Community vote |
| Fee parameters | Team-set | Governance proposal |
| New pair listings | Team decision | Community proposal |
| Treasury spending | Team-managed | DAO-controlled |
| Development direction | Team roadmap | Community governance |

### What Stays The Same

- Zero gas fees for users
- 873ms settlement
- MEV resistance
- Open-source code
- Permissionless access
