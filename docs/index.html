🐳One-Command Docker Setup

Spin up the entire stack with a single command. The docker-compose.yml brings up the ICP replica, deploys backend canisters, and starts the frontend dev server.

# Clone and run everything
git clone https://github.com/ItsNotAILABS/PARALLAX-Exchange-Clearinghouse.git
cd PARALLAX-Exchange-Clearinghouse
docker compose up
  • :8000 ICP Replica — Local Internet Computer network
  • :5173 Frontend — Vite dev server with hot reload
  • :6188 Storage Gateway
